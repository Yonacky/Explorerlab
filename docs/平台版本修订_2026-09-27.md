# 实验平台版本修订（2026-09-27）

本记录修订《Explorer_MC_Curiosity_实验方案_v1.0》§4.1 的开发平台选择。第一轮 G0–G2 使用 Minecraft Java 1.20.1、JDK 17、Fabric Loader 0.19.5 和 Fabric API 0.92.12+1.20.1。选择 1.20.1 是为了使用更成熟的 Fabric 模组生态和现成依赖，减少早期工程集成风险；它不构成实验效果优势的证据。v1.0 中的 1.21.1/JDK 21 设定不再用于当前开发运行。

本次改动只涉及平台版本，不改五臂比较、有效 tick 预算、允许的视觉与键鼠接口、信息隔离或评价指标。所有实验臂必须运行同一版本和同一模组构建。版本锁定文件在 `gradle.properties`，已安装基础件的 SHA-256 在 `config/installed-artifacts.sha256`。本机 HMCL 实例使用离线账户；这只是当前开发启动方式，正式实验记录须固定账户模式与联机功能禁用情况。

截至本记录，Fabric 实例和 ExplorerLab 的 G0 入口已在本机启动；一次进入世界的日志记录了 625 个服务端 tick 并正常退出。这个计数器尚不是有效 tick 控制器。键鼠桥、截图实测、世界暂停、双时钟核对、私有评分日志和 1,000 输入块验收仍未完成。完成 G0 和冻结完整构建哈希后，才能开始 pilot；当前运行不产生论文实验数据。
